# 青竹十六張 · Taiwanese 16-tile Mahjong AI (web version)

Play against the course-project Mahjong agent directly in your browser: **https://0hovoh0.github.io/taiwan-mahjong-web/v2/**

- Everything runs locally in the browser (Pyodide). No server and no sign-in are needed, and nothing is uploaded.
- The AI suggestion comes from the delivered behavior-cloned (V4.2 BC) model; the three opponents are rule-based teachers.
- Rules: the tw16-calls-0.6 single-hand profile used in the study.

This repository contains only the built web game. It was built from the private project repository for the 人工智慧導論 (Introduction to AI) final project, Group 127, National Central University.
